Overview

Warp lightweight font statistics from stdin samples. Built as a tiny zero-dependency Node toolkit with a library API and a stdin-friendly CLI.

Usage

git clone https://github.com/theworker02/warpfont.git
cd warpfont
node src/cli.js --help
node --test
